## Source bug found

In `include/linux/susfs.h`:

```c
#define KSTAT_SPOOF_CTIME_TV_SEC (1 < 8)
```

This is a comparison, not a bit flag; it evaluates to `1` and collides with `KSTAT_SPOOF_INO`. Patch 0002 changes it to `(1 << 8)`, consistent with the adjacent `KSTAT_SPOOF_* (1 << n)` flags. Keep kernel and userspace constants in sync when integrating the matching `ksu_susfs` tool.

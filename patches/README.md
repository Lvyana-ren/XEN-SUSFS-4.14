# Patch status

This directory is deliberately staged.

- `0001-susfs-v2.3.0-source-files.patch`: source-only bootstrap for a kernel tree that has no SUSFS source files yet.
- `0002-susfs-fix-ctime-bitmask.patch`: fixes the ctime spoof flag constant.
- `series.stage1`: applies those two patches in order on a clean baseline.

The kernel call-site integration is generated by the workflow because Xen-Kernel has local modifications relative to the upstream reference. The generated candidate must be reviewed and compile-tested; conflicts are reported separately and are not applied automatically.
